# Ask response structure

The user requests a simple question/response with further details, not a fixed executive-brief framework.

## Published interaction
An empty input produces no default answer. Enter or Answer question submits the question. Editing it clears the previous response. The submitted question is the heading; the answer leads directly, followed by explanatory paragraphs carrying source references. Further details and sources is collapsed by default. Architecture-map and dossier tools remain optional. Ask does not render the shared decision close or evaluation checklist.

## Content boundaries
Uncited generic story beats are not presented as evidence. The general retrieval path uses its actual evidence quotes instead of canned claims about bill of materials, power and qualification. A product name alone cannot route an unrelated question to the product overview. D100 funding prose was narrowed to the cited Blueprint plan and distinguishes the plan from proof of a closed round.

This change improves structure and removes irrelevant framing. The published engine still uses curated narratives for supported product/topic intents and extractive retrieval elsewhere. It does not yet provide model-written synthesis for arbitrary questions. The browser-generation experiment is saved locally in work/answer-generation-draft and the uncommitted answer-generator files; it is not required by this release.

## Verification
Typecheck, story/source checks and desktop/mobile browser checks. Browser cases include explicit keyboard submission, no default answer, removing stale answers, funding, comparison, diagnostic explanation, unsupported question, source links and absence of the shared checklist. A regression asserts that an undocumented SKU-10 warranty cannot receive its general product overview.
